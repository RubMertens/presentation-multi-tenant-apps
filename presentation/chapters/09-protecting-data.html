Protecting the data – TenantIdValueGenerator


public class TenantIdValueGenerator : ValueGenerator<string>
{
    public override string Next(EntityEntry entry)
    {
        if (entry is {
            Entity: ITenanted,
            Context: ApplicationDbContext db })
        {
            return db.TenantId;
        }

        throw new InvalidOperationException(
            "Could not generate a new TenantId");
    }

    public override bool GeneratesTemporaryValues => false;
}
File: ApplicationDbContext.cs — Automatically generates the TenantId for new entities from the current DbContext tenant.

Protecting the data – ApplicationDbContext


builder.Entity<HealingPod>(entity =>
{
    entity.HasKey(e => new { e.Id });
    entity.Property(e => e.TenantId)
        .IsRequired()
        .HasValueGenerator<TenantIdValueGenerator>();
    entity.HasIndex(e => e.TenantId);
    entity.HasQueryFilter(e => e.TenantId == TenantId);
});
File: ApplicationDbContext.cs — Configure HealingPod: required TenantId with auto-generation, index for performance, and a query filter for automatic tenant isolation.
