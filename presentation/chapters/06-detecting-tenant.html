Detecting a tenant

Let's start coding. First step: how do we detect which tenant is calling?

Detecting a tenant – Tenant.cs


public class Tenant
{
    public string Id { get; set; }
}
  

public class TenantContext
{
    public Tenant Tenant { get; set; }
}
File: Tenant.cs — Simple tenant model and a scoped context accessor to hold the current tenant.

Detecting a tenant – TenantExtensions


public static class TenantExtensions
{
    public static IServiceCollection AddTenantContext(
        this IServiceCollection services)
    {
        services.AddScoped<TenantContext>();
        services.AddTransient<Tenant>(p =>
            p.GetRequiredService<TenantContext>().Tenant
        );
        return services;
    }
}
File: Tenant.cs — Extension method to register TenantContext as scoped and Tenant as a transient that resolves from the context.

Building Middleware


public class TenantMiddleware(
    TenantContext tenantContext) : IMiddleware
{
    public Task InvokeAsync(HttpContext context,
        RequestDelegate next)
    {
        var subdomain = context.Request.Host
            .Host.Split('.')[0];
        tenantContext.Tenant = new Tenant
        {
            Id = subdomain
        };
        return next(context);
    }
}
  

builder.Services.AddScoped<TenantMiddleware>();
File: TenantMiddleware.cs — Extracts the subdomain from the host and sets it as the tenant ID. One-liner registration in Program.cs.
