How do you know which tenant to serve

What in what ways could we detect which tenant is calling?

Interactive moment - ask the audience how they would identify which tenant is making a request.

Query string


https://my-website.com?tenantId=customer1
Simplest approach - tenant ID in the query string. Easy to implement but visible to users and easy to tamper with.

Header


GET /page HTTP/1.1
Host: my-website.com
X-TenantId: customer1
Tenant ID in a custom HTTP header. Better for API-to-API communication. Not visible in the URL but requires client cooperation.

Subdomain


http://customer1.my-website.com/page
Tenant identified by subdomain. Clean URLs and natural branding per tenant. Requires DNS/wildcard configuration.
